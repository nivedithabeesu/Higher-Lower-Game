# Higher Lower Game 🎮

A fun Python command-line game where you compare two famous personalities, brands, or organizations and guess who has more followers.

## 🚀 Features

* Compare two different options.
* Guess which option has more followers.
* Keep track of your score.
* Random options for every round.
* Game continues until you give a wrong answer.

## 🛠️ Technologies Used

* Python

## 📚 Concepts Used

* Functions
* Loops
* Conditional Statements
* Lists
* Dictionaries
* Random Module
* User Input

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in PyCharm or any Python IDE.
3. Run the Python file.
4. Choose `A` or `B` based on your guess.
5. Try to get the highest score!
